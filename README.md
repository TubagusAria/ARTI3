**ARTI3** is an all-in-one high-performance autonomous development framework for AI coding agents. It synthesizes collaborative multi-perspective design, high-velocity parallel agent orchestration, uncompromising UI/UX craft floors, and pre-action verification gates into a single end-to-end engineering system.

---

## ⚡ The ARTI3 Core Thesis

Most AI coding agents suffer from three critical flaws:
1. **Premature Coding & Assumptions:** Jumping to edit code before understanding real constraints, schemas, and user trade-offs.
2. **AI Slop & Bland UI:** Defaulting to generic Inter font, centered purple gradients, pill capsule badges, cartoon emojis, and sterile 3-card grids.
3. **Fake Self-Certification:** Agents asserting "everything works" without objective, adversarial testing.

**ARTI3 fixes this by deploying a specialized squad with fact-forcing gates and strict craftsmanship floors.**

## 🎨 The Anti-AI-Slop Manifesto (Phase 2 Highlights)

- 🚫 **Banned: AI Pill / Capsule Badges:** Strictly reject rounded-full floating capsules with sparkles `✨` or glowing dots `●` above headings. Use clean typographic eyebrows or monolithic numbering (`01 / SECTION`) instead.
- 🚫 **Banned: Random UI Emojis:** Strictly avoid decorating headings, greetings, and buttons with cartoon emojis (`👋`, `📐`, `🚀`, `💡`).
- 💎 **Mandate: Lucide Icons (`lucide-react`):** Use unified vector icons with consistent stroke widths (`stroke-[1.5]` or `stroke-2`), optical alignment, and semantic color pairing.
- 🎛️ **Configurable Taste Dials (from tasteskill.dev):**
  - `DESIGN_VARIANCE` [1–10]: From familiar orthodox SaaS to bold editorial avant-garde.
  - `MOTION_INTENSITY` [1–10]: From instant subtle fades to kinetic, magnetic spring physics.
  - `VISUAL_DENSITY` [1–10]: From airy editorial whitespace to high-information Bloomberg cockpits.
- 🧩 **21st.dev Component Engineering:** Ingest production-tested community primitives (`npx shadcn@latest add "https://21st.dev/r/..."`) from Magic UI, Aceternity UI, Origin UI, and React Bits.

## 📦 Installation & Usage

### 1. Antigravity & Gemini CLI
Clone or copy this repository into your global or project skills folder:

```bash
# Global installation (recommended)
git clone https://github.com/TubagusAria/ARTI3.git ~/.gemini/config/skills/arti3

# Or project-specific installation
git clone https://github.com/TubagusAria/ARTI3.git .agents/skills/arti3
```

### 2. Claude Code / Cursor / OpenCode
You can install ARTI3 via the standard skills CLI:

```bash
npx skills add https://github.com/TubagusAria/ARTI3
```

### 3. Activating ARTI3
In your chat session with Antigravity or any supported agent, simply invoke:

```text
/arti3 Build a modern SaaS analytics dashboard with Next.js and Supabase
```

ARTI3 will immediately launch Phase 1, present an interactive multiple-choice questionnaire via `ask_question`, and assemble the squad.
